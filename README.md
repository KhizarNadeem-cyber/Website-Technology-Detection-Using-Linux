# 🔍 WhatWeb – Beginner Guide

## 📖 Overview

Today I learned how to use the **WhatWeb** tool in Linux.

WhatWeb is a reconnaissance tool used to identify technologies running behind a website. It helps cybersecurity learners and penetration testers gather useful information during the information gathering phase.

---

## ⚙️ What Can WhatWeb Detect?

Using WhatWeb, we can identify:

* CMS platforms (WordPress, Joomla, etc.)
* Web servers
* JavaScript libraries
* Frameworks
* Analytics tools
* Programming technologies

---

## 🛠️ Basic Usage

```bash
whatweb example.com
```

This command scans the target website and displays information about the technologies being used.

---

## 🧠 Why This Tool is Useful

Information gathering is one of the most important phases in cybersecurity.

Tools like WhatWeb help security researchers understand:

* What technologies are being used
* Possible attack surfaces
* Misconfigurations
* Potential vulnerabilities
